2. Module Overview

2.1 System Architecture

The HR module follows a service-oriented architecture with clear separation of concerns:
  • Controllers: Handle HTTP requests and responses
  • Services: Business logic layer (EmployeeService, LeaveService, UserService)
  • Models: Eloquent ORM models with relationships
  • Policies: Authorization rules and permissions
  • Views: Blade templates with Bootstrap 5

Database Structure

t_HRAttendance Daily attendance EmployeeID, Date, CheckIn, CheckOut ✓ Active

3.1.3 User Account Creation

Key Feature: Automatic user account creation with password reset email

Creation Methods:

    • Checkbox: "Create a user account for this employee"

    • Links via EmployeeId field
    • Sends password reset email
  2. After Creation:
    • Button on employee profile
    • Only visible if no user exists
    • Creates and sends reset link

3.3.2 Leave Application Workflow

Step 1: Employee Initiates
  • Select leave type
  • Choose dates (system calculates working days)
  • Add reason
  • Upload documents if required
  • View leave balance
  • Submit
Step 2: Supervisor Review
  • Receives notification
  • Reviews details
  • Checks team availability
  • Approves/Rejects/Requests Info
Step 3: HR Review (if needed)
  • Validates policy compliance
  • Checks documents
  • Final approval
  • Updates calendar

3.3.3 Leave Balance Tracking

  • Opening Balance: Based on grade entitlement
  • Accrued Balance: Monthly pro-rata for new employees
  • Taken Days: Sum of approved leave
  • Available: Opening + Accrued - Taken - Pending
  • Carry Forward: Max 7 days to next year

4. Detailed Workflows

4.1 Employee Onboarding Workflow

Phase 1: Pre-Arrival
  1. HR receives signed offer letter
  2. Create employee record in system
  3. Auto-generate Employee Number
  4. Check "Create user account" checkbox
  5. System sends welcome email
  6. Prepare workstation
Phase 2: First Day
  1. Employee arrives and checks in
  2. IT provides laptop and access
  3. HR collects documents
  4. Upload to employee profile
  5. Orientation with department
  6. Assign supervisor in system
Phase 3: Probation Period
  1. Regular check-ins with supervisor
  2. Performance tracking
  3. Mid-probation review
  4. End of probation evaluation
  5. Confirmation decision
  6. Update employment status

4.2 Leave Application Workflow

Step 1: Employee Initiates
  • Navigate to Leave Management
  • Fill application form
  • System validates balance
  • Checks for overlaps
  • Calculates working days
  • Notifies supervisor
Step 2: Supervisor Review
  • Receives email notification
  • Reviews leave details
  • Checks team availability
  • Approves/Rejects/Requests Info
  • Routes to HR if needed
Step 3: HR Final Approval
  • Verifies policy compliance
  • Checks documents
  • Final decision
  • Updates calendar
  • Notifies all parties
